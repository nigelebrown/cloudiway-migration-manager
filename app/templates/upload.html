Required columns: computer_number, source_email, target_email, first_name, last_name. Optional: middle_name.

These users go through the configured AD identity and Microsoft 365 readiness controls before migration.

Existing password → Cloudiway only

Required columns: source_email, target_email, password.

Optional reference columns: first_name, middle_name, last_name, computer_number.

No AD work is performed in this mode. The app does not create, modify, enable, or validate an AD account and does not reset the Rackspace password. It encrypts the supplied password, sends that source credential to Cloudiway for the selected users, and uses the existing configured Cloudiway source/target connectors. The Microsoft 365 target mailbox therefore needs to already exist and be usable.

The password is stored encrypted in MySQL and is not written to application logs. Use the exact current IMAP/Rackspace source password in the spreadsheet.
