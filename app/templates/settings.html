Rackspace Password Administration

{{'Configured' if rackspace_configured else 'Not configured'}}

This is only for changing individual Rackspace mailbox passwords. Cloudiway continues to use the existing IMAP migration connector.

The app will first authenticate the username/password with Rackspace Identity. If Rackspace also accepts the returned token for Cloud Office Email administration, automated password reset can use it. If not, the test will tell you that Email API keys are required.

Rackspace documents this as the supported authentication method for the Cloud Office Email API.
