A. Generate Rackspace bulk password file

The download is a ZIP containing two files: (1) the exact Rackspace mailbox-import CSV and (2) an administrative Excel password map with email, password, source_email, target_email, first_name, last_name, computer_number. For the Rackspace CSV, Username is the mailbox name only (for example nigel.brown), because Rackspace already knows the selected domain.

B. Confirm the Rackspace bulk update

After Rackspace finishes processing the file, upload either the generated Rackspace CSV or the generated Password Map Excel back here. The app checks the source email + password against what it generated. A successful match is treated as your confirmation that the password was applied in Rackspace.

C. Start confirmed users manually

Use this when you do not select automatic start above. You can start one person or any selected group. Only users showing manual_confirmed are accepted.
